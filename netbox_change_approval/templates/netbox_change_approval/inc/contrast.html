{% comment %} Keeps the plugin's buttons and badges readable under any NetBox color theme. Their colors come from NetBox's own variables (btn-success, text-bg-orange…), so a theme can make them unreadable: a white "warning" button with white icons, or a "danger" button the same color as the page. For each of our buttons and badges this checks the colors the browser actually shows: - text or icon too close to the button's own color: use the theme's text or background color, whichever stands out more (on outline buttons, shift the button's own color towards it just enough to read); - button too close to what is behind it: draw a thin outline in that same contrasting color (only then, so normal themes look unchanged). It runs again when the light/dark mode changes and when parts of the page are replaced (live refresh, htmx). Ours means: every button and badge on the plugin's own pages, and elsewhere those inside an element with an nbca class or a data-nbca-themed attribute. {% endcomment %}
