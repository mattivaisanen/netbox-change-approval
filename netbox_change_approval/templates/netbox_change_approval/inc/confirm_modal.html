{% load i18n %} {% comment %} Pop-up dialog for confirmations, like NetBox's own delete dialog. Rendered in (see inbox_nav.html) and moved into the page once it loads. - Links and buttons marked data-nbca-modal load their confirmation page's dialog version into it. Without JavaScript they open the full page. - Buttons marked data-nbca-confirm="Details" ask first, in place of the browser's OK/Cancel box. Optional: data-nbca-confirm-title (short question), data-nbca-confirm-label, data-nbca-confirm-class. - After a confirmed button's form is sent, the page it comes back to keeps its scroll position. - Links also marked data-nbca-inplace (the dashboard widget) send the dialog's form without leaving the page: on success the dialog closes, NetBox's message pops up and the link's row slides out (window.nbcaLive). Failures still move to the page the view sends them to. {% endcomment %}
